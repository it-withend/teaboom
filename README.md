# Карточка товара Teaboom.ru — «Ананасовый улун»

Тестовое задание на позицию HTML/Frontend-верстальщика: верхняя часть карточки товара
с выбором фасовки, ценой, артикулом и кнопкой «В корзину».

**Демо:** https://teaboom-product-card-eight.vercel.app

## Запуск

Готовый CSS уже лежит в `css/style.css`, поэтому сборка для просмотра не нужна.

**Вариант 1.** Открыть `index.html` в браузере.

**Вариант 2.** Через локальный сервер:

```bash
npm install
npm start          # http://localhost:3000
```

### Сборка стилей

Исходники лежат в `scss/`.

```bash
npm run build      # scss/style.scss → css/style.css
npm run watch      # пересборка при изменениях
```

## Структура

```
├── index.html
├── scss/
│   ├── style.scss          # точка входа
│   ├── _variables.scss     # палитра Teaboom, радиусы, брейкпоинты, миксин from()
│   ├── _base.scss          # сброс, контейнер, утилиты
│   ├── _breadcrumbs.scss
│   ├── _product.scss       # сетка карточки, галерея, заголовок
│   ├── _variants.scss      # выбор фасовки
│   ├── _buy.scss           # артикул, цена, кнопка
│   └── _about.scss         # короткое описание
├── css/style.css           # скомпилированные стили
└── js/main.js              # переключение фасовок и состояние кнопки
```

## Что сделано

- **Семантика.** `article` для карточки, `nav` + `ol` для хлебных крошек, `form` + `fieldset`/`legend`
  для фасовок, `dl` для артикула и характеристик, `s` для старой цены, `data` для цены.
- **Фасовки** — это настоящие `radio`. Ими можно управлять с клавиатуры (стрелками), они доступны
  скринридерам, а форма работает и без JS. Данные фасовки хранятся в `data-*` атрибутах инпута.
- **JS** без зависимостей. При смене фасовки обновляются цена, старая цена, артикул
  и процент скидки (он считается из цен). Цены форматируются через `Intl.NumberFormat('ru-RU')`.
  Если старая цена не больше текущей, старая цена и плашка скидки скрываются.
- **Кнопка «В корзину».** Обычное состояние, `:hover`, `:active` и `:focus-visible`.
  После клика кнопка на 2 секунды показывает «Добавлено» (реальная корзина не подключена).
- **Цена** обёрнута в `aria-live="polite"`, поэтому скринридер озвучивает её изменение.
- **Стилистика Teaboom.** Шрифт Open Sans и цвета сайта: жёлтый CTA `#f5d730`,
  светло-зелёный выбор `#e9f2c3` и кремовый фон `#fefcef`. Кнопка-«пилюля», как на сайте.
- **Именование** по БЭМ, Mobile First, Grid для раскладки, Flexbox внутри блоков.

## Адаптивность

| Ширина | Раскладка |
| --- | --- |
| **≥ 1200 px** (desktop 1440) | Две колонки. Фото «липкое» при прокрутке. Фасовки в один ряд из 4 штук |
| **768–1199 px** (tablet) | Две равные колонки. Фасовки сеткой 2×2. Кнопка растягивается на ширину панели |
| **< 768 px** (mobile 375) | Одна колонка. Панель «цена + В корзину» закреплена внизу экрана, чтобы кнопка покупки всегда была под пальцем, пока пользователь читает описание |

Проверено на 1440, 768 и 375 px: горизонтального скролла нет.
